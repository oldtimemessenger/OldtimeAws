name: Old Time product scope
description: User-stated product positioning and constraints for Old Time.
---

Old Time is a social-first network with an Instagram-style core, expanding into a connected ecosystem of people, communities, interests, city-level discovery, and chat. The product includes the existing PWA and a separate native iOS/Android app. The native first release uses its own account and cloud-synced text posts, likes, search, and profiles; it is not full PWA parity. Keep the existing PWA and device-local content intact, with no automatic migration or sync. Music can be an interest category but must not become the product focus.

**Why:** the user scoped native as a separate first release and explicitly required preserving PWA-local content.

**How to apply:** keep the native account and content separate from the PWA unless the user explicitly requests an opt-in connection or import. Keep work additive, social-first, and do not turn the product into a music-focused app.
